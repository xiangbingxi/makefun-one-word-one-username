Entry for the make.fun bounty [One Word, One Username, One Reward](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae).

The program writes the entrant's own make.fun username — one word and
nothing else — to `/output/entry.txt`:

```text
bingxi-xiang
```

## Run

```sh
python3 main.py
```

The output is UTF-8, 12 characters, with no trailing newline.
